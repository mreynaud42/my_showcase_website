# my_showcase_website

## 🌟 Description

my_showcase_website is a personal portfolio website designed to showcase my work and to help me learn how to build a website from scratch.
It is developed using React and TypeScript, and features a multilingual interface with interactive project pages.

## 🛠️ Technologies Used
- React
- TypeScript
- Vite (for fast bundling and development)
- i18next (for FR/EN multilingual support)
- Vercel (deployment)
- OVH (domain management)
- Figma (for design mockups)

## 📄 Pages and Features

The website includes the following pages:

- Home – landing page
- About – personal introduction
- Resume – CV and experience
- Projects – list of completed projects
- Project Detail – individual page for each project with description and technologies used

Main Features:
- Multilingual: French / English
- Fully responsive: works on desktop, tablet, and mobile

## 🚀 Live Website

The website is live here: https://mathis-reynaud.fr/

## 🗂️ Project Structure

Here’s a simplified overview of the project structure:
```
my_showcase_website/
├─ public/             # Static files (logo, favicon)
├─ src/
│  ├─ components/      # Reusable components (Header, Footer, LocalizedLink, Layout)
│  ├─ data/            # Project data (projects.ts)
│  ├─ i18n/            # Translation files and i18next configuration
│  ├─ pages/           # Website pages (Home, About, Projects, ProjectDetail, Resume)
│  ├─ App.tsx          # Main routing and app configuration
│  └─ main.tsx         # React entry point
├─ package.json         # Dependencies and scripts
├─ tsconfig.json        # TypeScript configuration
└─ vite.config.ts       # Vite configuration
```
